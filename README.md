# راهنمای آنکی — ترجمهٔ فارسی

ترجمهٔ فارسیِ [راهنمای رسمی آنکی](https://docs.ankiweb.net/) (نسخهٔ انگلیسی همیشه به‌روزترین نسخه است).

**خواندن راهنما:** <https://msadrashakouri.github.io/anki-manual/>

## وضعیت ترجمه

فهرست کامل فصل‌ها و میزان پیشرفت ترجمه در [PROGRESS.md](PROGRESS.md) آمده است.
ترجمه همه ۵۷ فصل راهنما کامل شده است.

## واژه‌نامه

ترجمه‌های استاندارد اصطلاحات آنکی در [terms.md](terms.md) فهرست شده‌اند و
ابزار `tools/fa/check.py` یکدستی اصطلاحات و سلامت ساختاری پرونده‌ها را به‌طور خودکار بررسی می‌کند.

## مشارکت

ترجمه نیاز به به‌روز ماندن در برابر [مخزن اصلی](https://github.com/ankitects/anki-manual) دارد؛
هرگونه کمک برای ترجمه فصل‌های باقی‌مانده یا بازبینی فصل‌های موجود خوش‌آمد است
(pull request یا issue).

## همگام‌سازی با نسخهٔ انگلیسی

گردش کار «Sync Upstream» هر روز مخزن اصلی را بررسی می‌کند و برای هر تغییر جدید
یک issue با برچسب `sync` می‌سازد تا مشخص باشد کدام فصل‌ها نیاز به ترجمهٔ مجدد دارند:

```bash
gh issue list --label sync
```

شاخهٔ `upstream` آینهٔ مخزن اصلی است. چون تاریخچهٔ مخزن اصلی گاهی شامل تغییرات
پرونده‌های `.github/workflows/` است (برای نمونه به‌روزرسانی خودکار نسخهٔ اکشن‌ها
توسط Dependabot) و `GITHUB_TOKEN` هرگز اجازهٔ ایجاد یا تغییر چنین پرونده‌هایی
را ندارد، برای به‌روزرسانی این شاخه یک personal access token لازم است: توکن
کلاسیک با دسترسی‌های `repo` و `workflow` یا توکن fine-grained با دسترسی
نوشتنِ Contents و Workflows (فقط برای همین مخزن). توکن را با نام `SYNC_TOKEN`
در Settings > Secrets and variables > Actions ذخیره کنید. تا وقتی این راز
تنظیم نشده باشد، ساخت issueها همچنان کار می‌کند اما شاخهٔ `upstream` پس از
کامیت‌هایی که پرونده‌های گردش کار را تغییر می‌دهند به‌روز نمی‌شود و اجرا با
پیامی راهنما شکست می‌خورد.

## برون‌بری برای وب‌سایت مستندات جدید

پس از دریافت مخزن اصلی آنکی در `~/anki`، ترجمه را با دستور زیر به ساختار Mintlify
در `docs-site/fa/manual` برون‌بری کنید:

```bash
python3 tools/fa/export_mintlify.py --anki-repo ~/anki
```

این ابزار ۵۵ صفحهٔ فعلی راهنما را تبدیل می‌کند، پیوندها و calloutها را با MDX
سازگار می‌کند و از رسانه‌های مشترک موجود در مخزن اصلی استفاده می‌کند.
